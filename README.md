# 🌐 Personal Portfolio Website

A modern, professional, and fully responsive **portfolio website** built using **HTML, CSS, and JavaScript**.  
It showcases my skills, experience, and projects in a clean and elegant design.

---

## 🖋️ Overview

This portfolio serves as my personal website — a place to highlight my:
- Background and experience  
- Featured projects  
- Technical skills  
- Education and certifications  
- Contact information  

It’s designed to be fast, accessible, and visually appealing across all devices.

---

## 🛠️ Tech Stack

- **HTML5** – Structure & content  
- **CSS3** – Styling and responsive layout  
- **JavaScript (ES6)** – Interactivity and animations  
- **GitHub Pages** – Hosting and deployment
